# Deployment

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run lint
npm run typecheck
npm run build
```

## Preview

```bash
npm run preview
```

## Vercel

- Framework: Vite / React-compatible build through vinext.
- Build command: `npm run build`.
- Output: generated by vinext.
- Environment: set public values and server-only values separately.
- SPA routing: product routes are app routes, not client-only fragments.

## Backend

AI, MAX and persistence should run server-side. Current routes:

- `/api/leads`
- `/api/chat`

For Railway or Vercel Functions, deploy the backend routes with:

- `GEMINI_API_KEY`
- `MAX_BOT_TOKEN`
- `MAX_CHAT_ID`
- database or CRM variables
- CORS policy for the production domain

## Domain

Replace the placeholder production domain in `config/business.ts`, `public/robots.txt` and `public/sitemap.xml` if the final domain is not `fasadof.ru`.
